# 🌤️ Weather App

A modern weather app built with Flutter. Search any city and get current weather, hourly and 5-day forecast. Background colour changes with the weather.

## Features
- City search with live weather (Open-Meteo API, no key needed)
- Hourly and 5-day forecast
- Recent searches saved locally with Hive

## Run
```bash
git clone https://github.com/YAMUNA RANI/weather_app.git
cd weather_app
flutter pub get
flutter run -d chrome
```
